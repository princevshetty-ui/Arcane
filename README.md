# Arcane

> **Status: Unfinished / experimental project**

Arcane is an experimental AI-powered PDF knowledge graph project. The goal is to transform information contained in PDF documents into structured concepts, entities, and relationships, then visualize those relationships as an interactive knowledge graph.

This repository represents an earlier development attempt and is **not a finished product**. It is being kept as a record of the project and may be resumed and expanded later.

## Concept

The planned workflow is:

1. Upload or provide a PDF document.
2. Extract useful text and information from the document.
3. Use an AI model to identify concepts, entities, events, and relationships.
4. Convert the extracted information into structured graph data.
5. Display the resulting knowledge graph interactively.

## Tech Stack

### Frontend

- React
- Vite
- React Force Graph (2D/3D)
- Three.js
- Tailwind CSS utilities
- Framer Motion
- Lucide React

### Planned / Backend Components

The project was designed around PDF processing and AI-assisted extraction, with the graph visualization forming the main frontend experience.

## Current Status

The project is **unfinished**. Development was paused before all planned functionality was completed and integrated into a final working application.

The repository is retained as an experimental project that can be revisited and developed further in the future.

## Future Direction

If development resumes, the next stages would include completing the PDF ingestion pipeline, connecting AI-based entity and relationship extraction, defining a stable graph data format, and integrating the backend with the existing interactive graph interface.
